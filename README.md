# Daily Motivational Quotes

A simple ReactJS web application that displays a motivational quote for today and yesterday.  
Originally intended to serve as an API for fetching motivational quotes, the app now works as a stand-alone single page application (SPA).  

All quotes are stored in a local JSON file.

---

## 🌐 Live Demo
Check it out here: [Daily Motivational Quotes](https://programmmerjosh.github.io/daily-motivational-quotes/)

---

## 🚀 Features
- Displays **today’s motivational quote**
- See **yesterday’s quote**
- Minimal, distraction-free UI
- Single Page Application built with ReactJS

---

## 🛠️ Tech Stack
- [ReactJS](https://reactjs.org/)

## 📦 Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/programmmerjosh/daily-motivational-quotes
   ```
2. Navigate into the project folder:
   ```bash
   cd daily-motivational-quotes
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   ```
5. Open your browser at [http://localhost:3000](http://localhost:3000).
